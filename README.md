# Garmin MK3i — GasBlend

GasBlend is a gas blending calculator for Garmin Descent dive computers.

Designed for recreational and technical divers, it calculates oxygen, helium, and air additions required to achieve a desired Nitrox or Trimix blend using partial pressure blending.

> ⚠️ Planning aid only. Always verify calculations and dive within your training, procedures and dive computer limits.

## Features

- Nitrox and Trimix calculations
- Partial pressure blending
- Helium, oxygen, and air top-up calculations
- Fast watch-friendly interface
- Works directly on Garmin Descent watches
- No internet connection required

## Usage

Enter:

- Starting pressure
- Starting O₂ %
- Starting He %
- Target pressure
- Target O₂ %
- Target He %

GasBlend calculates:

- Helium to add
- Oxygen to add
- Air top-up
- Resulting gas mix

## Requirements

- Garmin Descent series dive computer
- Connect IQ compatible device

## Disclaimer

GasBlend is intended as a planning and educational tool only.

Always analyze and verify your final gas mix using appropriate oxygen and helium analyzers before diving. The user is solely responsible for all gas blending and dive planning decisions.
